# DSC 623 - Database Project

Ian Keith, Ruohong Zhu, Vishvaadarshan Ashoknathan  
University of Miami, Spring 2026

**About:**

This is a database design and implementation project for DSC 623. We built a rental company database from scratch, starting with an ER diagram, designing the schema, and finally implementing it using Python and SQLite.

**reports/**
- Part 1 — Entity-Relationship design and diagram
- Part 2 — Relational schema, integrity constraints, and query planning
- Part 3 — Implementation report with table outputs and query results

**code/**
Full Python/SQLite implementation of the database

## Queries covered

1. All vehicles hired by a specific client
2. Vehicles above 30,000 miles hired during 2025
3. Total number of Honda vehicles across all outlets
4. Vehicle make with the highest daily hire rate
5. Top 10 outlets with the most staff
